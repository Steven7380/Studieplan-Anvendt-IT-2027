Faglig innhold i emnet

Emnet Applikasjonsutvikling med KI bygger videre på eksisterende emne Applikasjonsutvikling for web (APP2000). Det er fortsatt et fullstack-kurs, men man skal nå bygge løsninger både for web og mobil, og det legges sterk vekt på KI-drevet utvikling, blant annet spec-driven development der man bruker KI til å generere kode fra spesifikasjoner.

Studentene utvikler løsninger i grupper, med realistisk oppdragsgiver eller selvvalgt case. Undervisningen kombinerer forelesninger, praktiske øvinger og prosjektveiledning.

Emnet forutsetter kunnskap om programmering, databaser og web-utvikling fra 1. år, samt grunnleggende forståelse for operativsystemer og nettverk fra 2. år, høst.

Læringsutbytte

Kunnskap

Etter fullført emne skal studenten ha kunnskap om:

  • Språk og verktøy for utvikling av web- og mobilapplikasjoner (JavaScript/TypeScript, React, React Native)
  • Dokumentobjektmodellen for nettsider (DOM) og komponentbasert utvikling
  • Problemstillinger knyttet til sikkerhet og personvern i webapplikasjoner
  • Relevante webstandarder, inkludert HTML, CSS, WCAG og HTTP/HTTPS
  • Programvarearkitektur for web- og mobilapplikasjoner
  • Spec-driven development: bruk av KI til å generere kode fra kravspesifikasjoner
  • KI-API-er og integrasjon av språkmodeller i applikasjoner (OpenAI API, Claude API m.fl.)
  • DevOps-praksis med skytjenester, containerteknologi og automatisert distribusjon (CI/CD)
  • Autentisering og autorisasjon i moderne applikasjoner (JWT, OAuth 2.0)

Ferdigheter

Etter fullført emne skal studenten kunne:

  • Delta i alle deler av applikasjonsutvikling for å løse praktiske problemer
  • Analysere og beskrive krav til web- og mobilapplikasjoner
  • Utvikle og teste fullstack-applikasjoner med kode på klient- og tjenerside
  • Bygge mobilapplikasjoner med React Native som deler kode med web-løsningen
  • Bruke relevante utviklingsverktøy, rammeverk og bibliotek
  • Anvende spec-driven development ved å bruke KI aktivt i alle faser av utviklingen
  • Integrere KI-API-er i egne applikasjoner
  • Bruke Git og GitHub for versjonskontroll, kodegjennomgang og deling av kode
  • Sette opp og bruke CI/CD-pipelines og deployere til en skyplattform

Generell kompetanse

Etter fullført emne skal studenten kunne:

  • Planlegge og gjennomføre prosjekter i grupper med smidig metodikk
  • Jobbe med oppdragsgivere i utviklingsprosjekter på en profesjonell måte
  • Dokumentere og presentere resultater med live demo for oppdragsgiver
  • Reflektere over samfunnsmessige konsekvenser av digitaliseringen og KI-drevet utvikling

Emnets innhold

# Tema Nøkkelbegreper / verktøy
1 Introduksjon og moderne fullstack-arkitektur React, Node.js, Express, monorepo
2 Spec-driven development med KI Prompt engineering, AI-kodeassistanse, Copilot
3 React for web – avansert hooks, context, React Query, routing
4 React Native for mobil Expo, native komponenter, plattformdifferanser
5 Backend og REST API Express, middleware, validering, feilhåndtering
6 Autentisering og autorisasjon JWT, OAuth 2.0, session, RBAC
7 KI-API-er og LLM-integrasjon OpenAI API, Claude API, RAG-mønster, streaming
8 Testing og kvalitetssikring Jest, React Testing Library, Playwright, CI
9 DevOps og deployment Docker, GitHub Actions, Vercel/Railway/AWS
10 Prosjektpresentasjoner Live demo, retrospektiv, faglig oppsummering

Forkunnskapskrav

Studenten forventes å ha grunnleggende kunnskap innen:

  • Programmering i JavaScript og/eller TypeScript (fra Programmering og Objektorientert programmering)
  • Web-utvikling med HTML og CSS
  • Databaser og SQL (fra Databaser)
  • Versjonskontroll med Git og GitHub
  • Grunnleggende systemutvikling og smidige metoder (fra Praktisk prosjekt)
  • Containerteknologi og nettverk (fra Operativsystemer og nettverk)
