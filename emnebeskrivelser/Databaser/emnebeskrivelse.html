Faglig innhold i emnet

Emnet Databaser er en sammenslåing og utvidelse av de tidligere emnene Database 1 og Database 2, og dekker relasjonelle databaser, NoSQL-databaser og skybaserte lagringsløsninger i ett semester.

Studenten lærer å modellere data, skrive SQL, administrere databaser og velge riktig databaseteknologi for ulike brukstilfeller. Det legges særlig vekt på moderne databaser i skylandskapet. Noe klassisk databasestoff (som avansert normalisering og lagrede prosedyrer) behandles mer overfladisk enn i gammel plan for å gi rom for de nye temaene.

Læringsutbytte

Kunnskap

Etter fullført emne skal studenten ha kunnskap om:

  • Databasebegreper og relasjonsdatabasemodellen: tabeller, nøkler, relasjoner
  • SQL: DDL (CREATE, ALTER, DROP) og DML (SELECT, INSERT, UPDATE, DELETE)
  • Brukerhåndtering og tilgangskontroll i databaser
  • NoSQL-databaser: dokumentdatabaser (MongoDB), nøkkel-verdi-lager (Redis) og søkemotorer
  • Skybaserte databaser: AWS RDS, Azure SQL, Google Cloud SQL og Firebase
  • Databaseoptimalisering: indekser, query-analyse og ytelsesmålinger

Ferdigheter

Etter fullført emne skal studenten kunne:

  • Skrive SQL DDL-setninger for å opprette og endre databasestrukturer
  • Skrive SQL DML-setninger inkludert komplekse JOIN-spørringer og aggregering
  • Lage datakonseptuelle modeller (ER-diagrammer) og implementere dem som tabeller
  • Normalisere en datamodell til 3. normalform
  • Opprette og administrere brukere og rettigheter i en relasjonsdatabase
  • Bruke MongoDB til å opprette samlinger og kjøre dokumentspørringer
  • Koble en applikasjon til en skybasert database
  • Bruke KI-verktøy (f.eks. ChatGPT) til å generere og forklare SQL-spørringer

Generell kompetanse

Etter fullført emne skal studenten:

  • Forstå databaseteknologi som grunnmur for moderne applikasjoner og KI-systemer
  • Kunne velge riktig databaseteknologi for et gitt brukstilfelle
  • Reflektere over datakvalitet, datasuverenitet og etisk bruk av data
  • Ha erfaring med selvstudium og problemløsning med digitale verktøy og KI-assistanse

Emnets innhold

# Tema Nøkkelbegreper / verktøy
1 Introduksjon til databaser DBMS, relasjonsdatabasemodellen, PostgreSQL
2 Datamodellering ER-diagram, entiteter, attributter, relasjoner
3 SQL – DDL CREATE TABLE, PRIMARY KEY, FOREIGN KEY, ALTER
4 SQL – Grunnleggende DML SELECT, INSERT, UPDATE, DELETE, WHERE
5 SQL – Avanserte spørringer JOIN, GROUP BY, HAVING, subspørringer, views
6 Normalisering 1NF, 2NF, 3NF, funksjonelle avhengigheter
7 Transaksjoner og sikkerhet ACID, BEGIN/COMMIT/ROLLBACK, GRANT, REVOKE
8 NoSQL – dokumentdatabaser MongoDB, samlinger, dokumenter, aggregeringspipeline
9 NoSQL – andre typer og brukstilfeller Redis, Elasticsearch, CAP-teoremet
10 Skybaserte databaser AWS RDS, Azure SQL, Google Cloud SQL, Firebase
11 Databasevalg i praksis Relasjonell vs. NoSQL, skytjenester, brukstilfeller
12 Ytelse og oppsummering Indekser, EXPLAIN, query-optimering, valg av DB-teknologi
