Faglig innhold i emnet

Emnet gir en solid innføring i fullstack KI-støttet applikasjonsutvikling for web og mobil. På klientsiden (frontend) blir det lagt vekt på bruk av aktuelle rammeverk og biblioteker, i tillegg til HTML, CSS og JavaScript/TypeScript. På tjenersiden (backend) blir det lagt vekt på utvikling av API-er og programmering mot databaser.

Læringsutbytte

Kunnskap

Etter fullført emne skal studenten ha kunnskap om:

  • språk og verktøy for fullstack-utvikling av applikasjoner tilpasset web og mobil
  • dokumentobjektmodellen for nettsider (DOM)
  • utvikling og bruk av web-API-er, inkludert REST API-er
  • programmering mot relasjonsdatabaser og NoSQL-databaser
  • problemstillinger knyttet til sikkerhet i applikasjonsutvikling
  • relevante standarder, inkludert HTML, CSS, WCAG og HTTP/HTTPS
  • programvarearkitektur for web- og mobil-applikasjoner
  • DevOps-praksis, med bruk av skytjenester, kontainerteknologi, mikrotjenester og automatisert distribuering av applikasjoner (CI/CD)
  • KI-støttet applikasjonsutvikling

Ferdigheter

Etter fullført emne skal studenten kunne:

  • utvikle og teste applikasjoner for web og mobil, med programmering både på klientsiden (frontend) og tjenersiden (backend)
  • bruke relevante programmeringsspråk, utviklingsverktøy, rammeverk og bibliotek
  • bruke KI i applikasjonsutvikling på en effektiv måte
  • bruke verktøy som Git og GitHub for versjonskontroll og deling av kode

Generell kompetanse

Etter fullført emne skal studenten kunne:

  • utvikle egne kunnskaper og ferdigheter innen applikasjonsutvikling
  • kjenne til teknologiske trender på fagfeltet
