Faglig innhold i emnet

Emnet Programvaretesting gir studentene praktiske ferdigheter med moderne verktøy og metoder som er etterspurt i IT-bransjen.

Emnet dekker testnivåer – fra isolerte enhetstester til integrasjonstester og ende-til-ende-tester – for applikasjoner bygget med JavaScript og TypeScript i miljøer som Node.js og React. Det legges vekt på at testingen er en integrert del av utviklingsprosessen, ikke noe som gjøres i ettertid.

Emnet bygger på kunnskaper fra tidligere emner i programmering, databaser, web-utvikling og systemutvikling. Undervisningen kombinerer teori, praktiske øvinger og et gruppebasert prosjektarbeid.

Læringsutbytte

Kunnskap

Etter fullført emne skal studenten ha kunnskap om:

  • Grunnleggende begreper innen programvaretesting: testtilfelle, testsuitt, testprosess, feil, defekt og testdekning
  • Testpyramiden og de ulike testnivåene: enhets-, integrasjons- og ende-til-ende-testing
  • Ulike testmetoder: black-box-testing, white-box-testing og grå-boks-testing
  • Mocking, stubbing og spies som teknikker for å isolere enheter under test
  • Asynkron testing og utfordringer knyttet til timing og sideeffekter
  • Hva integrasjonstesting er og hvordan REST API-er testes systematisk
  • Grunnleggende prinsipper for testing av brukergrensesnitt og React-komponenter
  • Ende-til-ende-testing av web-applikasjoner og hva som skiller det fra lavere testnivåer
  • Testdekning (code coverage) som kvalitetsmål og dens begrensninger
  • Vanlige sikkerhetssårbarheter i web-applikasjoner (OWASP Top 10) og grunnleggende sikkerhetstesting
  • Ytelsestesting og de vanligste metodene for å avdekke flaskehalser
  • Kontinuerlig integrasjon (CI) og automatisering av testprosessen i en CI/CD-pipeline
  • Teststrategier, teststyring og rollen testing spiller i ulike utviklingsmetodikker (Scrum, Kanban)

Ferdigheter

Etter fullført emne skal studenten kunne:

  • Sette opp et testmiljø med Jest eller Vitest i et JavaScript/TypeScript-prosjekt
  • Skrive strukturerte enhetstester med describe, it/test og relevante expect-matchers
  • Anvende TDD-syklusen (Red–Green–Refactor) i praktisk programvareutvikling
  • Bruke jest.mock(), jest.fn() og jest.spyOn() for å mocke moduler og avhengigheter
  • Skrive tester for asynkrone funksjoner med async/await, Promises og fake timers
  • Sette opp og bruke Supertest for å teste Node.js/Express REST API-er
  • Teste CRUD-operasjoner og feilhåndtering i et REST API
  • Bruke React Testing Library til å teste React-komponenter på et semantisk og brukersentrert nivå
  • Skrive ende-til-ende-tester med Playwright for å validere komplette brukerreiser
  • Generere og tolke testdekningsrapporter med Jest --coverage
  • Identifisere og teste for vanlige sikkerhetsproblemer som manglende inputvalidering og SQL-injeksjon
  • Planlegge og gjennomføre enkle ytelsestester og tolke resultatene
  • Sette opp automatiserte testpipelines med GitHub Actions
  • Begrunne og velge hensiktsmessig teststrategi for et gitt programvareprosjekt
  • Presentere og forsvare testarbeid muntlig i en prosjektsammenheng

Generell kompetanse

Etter fullført emne skal studenten:

  • Kunne reflektere over kvalitet, risiko og ansvar i utvikling og testing av programvare
  • Kunne kommunisere testfaglige vurderinger til utviklere, prosjektledere og andre interessenter
  • Forstå hvordan systematisk testing bidrar til robuste, sikre og brukervennlige løsninger
  • Kunne arbeide strukturert og etterprøvbart med kvalitetssikring i team

Forkunnskapskrav

Studenten forventes å ha grunnleggende kunnskap innen:

  • Programmering i JavaScript og/eller TypeScript
  • Web-utvikling med HTML, CSS og React (eller tilsvarende rammeverk)
  • Serverside-utvikling med Node.js og Express
  • REST API-er og HTTP-protokollen
  • Versjonskontroll med Git og GitHub
  • Grunnleggende systemutvikling og smidige metoder

Læringsaktiviteter

Emnet gjennomføres gjennom forelesninger, praktiske øvinger, demonstrasjoner av testverktøy og gruppebasert prosjektarbeid. Studentene arbeider både med korte testoppgaver underveis og med en større testsuite som knytter teori til realistiske utviklingsscenarier.

Skriftlig eksamen

Individuell skriftlig eksamen på 4 timer. Ingen hjelpemidler er tillatt. Eksamen teller 100 % av endelig karakter (A–F). Eksamen inneholder flervalgsoppgaver, kortsvarsoppgaver og praktisk kodeoppgave.

Obligatoriske aktiviteter

Prosjektoppgaven er obligatorisk og må være bestått for at studenten skal kunne fremstille seg til skriftlig eksamen.

Eksamensformer

Emnet vurderes med en kombinasjon av obligatorisk prosjektoppgave og individuell skriftlig eksamen. Vurderingsformen er valgt for å kombinere praktiske testferdigheter med individuell faglig forståelse.

Hjelpemidler til eksamen

Ingen hjelpemidler er tillatt til skriftlig eksamen. Dette fremgår også av emneinformasjonen øverst på siden.

Annet

Emnet oppdateres fortløpende i takt med utviklingen i testverktøy, rammeverk og praksis i bransjen. Bruk av KI-verktøy skal skje i samsvar med emnets læringsmål og universitetets regler for akademisk redelighet.
